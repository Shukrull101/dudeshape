# Изображения Dudeshape

Положи файлы прямо в эту папку: `src/shared/assets/`. Имена учитываются точно, особенно регистр букв.

| Файл | Где используется |
|---|---|
| `hero.jpg` | первый слайд Hero и временно иллюстрация в блоке отзывов |
| `productLotion.png` | второй слайд Hero, вторая карточка товара и блок Beauty |
| `productOil.jpg` | третий слайд Hero и первая карточка товара |
| `facebook.png` | иконка Facebook в футере |
| `instagram.png` | иконка Instagram в футере |
| `twitter.png` | иконка Twitter в футере |

`assetImages.js` автоматически подбирает эти файлы с помощью Vite `import.meta.glob`. Если отдельное фото пока отсутствует, используются SVG-заглушки для товарных/hero-изображений, а для соцсетей — иконки из `lucide-react`.

В присланном наборе нет отдельного портрета покупателя и отдельного фото для блока Beauty, поэтому пока используются имеющиеся фото товара. Если пришлёшь эти два изображения, их можно подключить отдельно.
