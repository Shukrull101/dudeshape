# Dudeshape — интернет-магазин косметики

Одностраничный адаптивный лендинг магазина косметики. Интерфейс и стилизация компонентов построены на **React + Tailwind CSS v4**, а Vite используется для разработки и production-сборки.

## Возможности

- Адаптивный интерфейс для компьютеров, планшетов и телефонов.
- Шапка в `src/widgets/Header.jsx` и подвал в `src/widgets/Footer.jsx`.
- Секции главной страницы вынесены в отдельные компоненты.
- Hero-слайдер с автопрокруткой, стрелками и индикаторами.
- Поиск по товарам с выпадающими подсказками.
- Корзина: добавление, удаление товаров, изменение количества и сумма заказа.
- Блок достижений, отзывы и форма подписки с валидацией email.
- Изображения и логотипы находятся в `src/shared/assets/`.

## Технологии

- React
- Vite 8
- Tailwind CSS 4 через официальный плагин для Vite
- lucide-react для иконок

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который Vite выведет в терминале (обычно `http://localhost:5173`).

Production-сборка:

```bash
npm run build
npm run preview
```

## Изображения

Изображения импортируются из `src/shared/assets/assetImages.js`. В архиве лежат SVG-заглушки, которые нужно заменить финальными фотографиями. Обновляй импорты и расширения файлов в `assetImages.js` при замене изображений.

## Примечание

Поиск и корзина работают на стороне браузера. Реальные платежи и отправка email требуют отдельного backend-сервиса или интеграции со сторонним провайдером.


## Подключение фотографий

Положи перечисленные изображения в `src/shared/assets/`: `hero.jpg`, `productLotion.png`, `productOil.jpg`, `facebook.png`, `instagram.png`, `twitter.png`. Они используются через `src/shared/assets/assetImages.js`. Благодаря `import.meta.glob` отсутствующий файл не ломает сборку: для фото останется аккуратная SVG-заглушка, для соцсетей — запасная иконка.
